# Arity

> Arity is the number of arguments that a function or an operator takes

```TS
function foo(a,b){}
```

> This function take two arguments, so it's arity is 2

> Even in operators, when we say unary, binary, ternary operators we mean it's arity

> a++, a+b, a?b:c

> ++ is unary operator: takes one argument

> + is a binary operator in this case: takes arguments 

> ? : is a  ternary operator: takes three arguments


> This is useful in function overloading, currying etc.
